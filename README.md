# Task Management REST API

A RESTful Task Management API built using Node.js, Express.js and SQLite.

## Features

- RESTful API
- CRUD operations
- SQLite database
- Input validation
- Error handling
- JSON responses
- Swagger API documentation
- Proper HTTP status codes

## Technologies Used

- Node.js
- Express.js
- SQLite
- Express Validator
- Swagger
- Postman
- Git
- GitHub
